# ARPipe — Failures and Lessons

## Shared-worktree corruption
A concurrency incident overwrote active production modules.
Lesson: one session = one worktree = one task.

## Hidden bad pages
Document-level quality can pass while individual pages are poor.
Lesson: retain page-level diagnostics.

## `is given below`
A broad pattern could match pointer language.
Lesson: explicit pointer guards matter.

## Silent acquisition failures
Original fetching did not persist structured failure reasons.
Lesson: acquisition attribution requires per-attempt telemetry.

## Legacy font
Legacy evidence is not the same as text corruption.

## Coverage denominators
Expected, discovered, downloaded, MDA-located, and accepted populations are different.

## Current access variation
Current failure/success timing differences do not prove the historical cause.
